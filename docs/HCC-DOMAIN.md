# HCC-DOMAIN · 领域术语与红线

日期：2026-10-22。用途：给开发与内容核对共用的一张表。**不是临床指南摘录，术语解释只用于「让患者读懂报告里写了什么」，不构成医学建议。**

## 1. 病因（背景维度）

| 项 | 记录什么 |
| --- | --- |
| HBV | HBsAg、HBV DNA、抗病毒药名与开始日期、免疫/激素/化疗前筛查日期 |
| HCV | 抗体与原病毒学状态（有则记录） |
| 酒精 | 饮酒量原话 |
| MASLD / 代谢相关脂肪性肝病 | 是否合并糖尿病、体重变化 |
| 其他 | 黄曲霉毒素暴露史等（患者自述） |

## 2. 肝功能储备（A 轨）

| 项 | 说明 | 记录规则 |
| --- | --- | --- |
| 白蛋白 g/L | 合成功能 | 原值 |
| 总胆红素 μmol/L | 排泄功能 | 原值 |
| INR / PT | 凝血 | 原值 |
| 血小板 10⁹/L | 门脉高压线索（脾亢） | 原值 |
| ALT / AST | 肝细胞损伤 | 原值 |
| Child-Pugh 评分/分级 | 5 项综合 | **只存医生记录**，工作台不重算 |
| ALBI | 0.66×log10(胆红素) − 0.085×白蛋白 | **派生展示**，任一成分缺测不出分；分级阈值 ≤−2.60 / ≤−1.39 / >−1.39 |
| 腹水 | 无 / 少 / 中 / 大量 | 医生记录 |
| 肝性脑病 | 无 / 1–4 级 | 医生记录；诱因由医生判断 |
| ICG-R15 | 术前储备 | 有则记录 |

ALBI 分级只作记录，**解释为预后是红线**。

## 3. 肿瘤负荷（B 轨）

| 项 | 记录什么 |
| --- | --- |
| 结节数目 / 最大径 | 影像原值；单位 mm |
| 段位（Couinaud S1–S8） | 逐灶记录 |
| LI-RADS | LR-1…LR-5 / LR-M / LR-TIV / LR-NC，原值 |
| 门静脉癌栓 Vp0–Vp4 | 独立字段，不写进备注 |
| 肝外扩散 | 有 / 无 |
| AFP ng/mL | 数值，可作对数趋势 |
| PIVKA-II mAU/mL | 数值 |

## 4. 分期体系（并存，不换算）

- **BCLC**（0 / A / B / C / D）：把肝功能、肿瘤负荷、体能状态与预后放在一个框架里。
- **CNLC 2022**（Ia / Ib / IIa / IIb / IIIa / IIIb / IV）：中国肝癌分期，与治疗路径绑定更紧。
- **AJCC/UICC TNM**：病理分期，只有切除后才完整。

工作台只记录「医生说的是哪一套」，并在 UI 上并列展示。

## 5. 治疗路径

| 路径 | 记录要点 |
| --- | --- |
| 手术切除 | 术式、切缘、病理（分化、MVI）、残肝比例 |
| 消融（RFA/MWA） | 次数、部位 |
| TACE / HAIC | 次数、起止、栓塞后事件 |
| 钇-90（TARE）/ 放疗 | 方案原文 |
| 系统治疗 | 方案名（靶向 / 免疫 / 联合）、周期、疗效原文、肝毒性 |
| 移植评估 | 只记录评估结论，不做移植后管理 |
| **转化治疗** | intent = conversion；每次可切除性评估新增一行 |

## 6. 安全事件类型

| kind | 常见表现 | 记录 |
| --- | --- | --- |
| post_embolization | 发热、腹痛、恶心（TACE 后数日） | 起止、分级、医生处理 |
| liver_toxicity | ALT/AST/胆红素升高 | 与用药时间对齐；不判断停药 |
| irae | 免疫相关不良反应 | 分级与处理原话 |
| variceal_bleed | 黑便、呕血 | 立即就医提示 |
| encephalopathy | 意识改变 | 分级；诱因由医生判断 |
| ascites / SBP | 腹胀加重、发热 | 记录 |
| hbv_reactivation | DNA 由阴转阳 | 与筛查日期对齐 |

## 7. 红线（文案与功能）

- 禁：建议治疗 / 可能复发 / 可以停药 / 无需就医 / 推荐方案 / 治愈率 / 生存率 / 复发概率。
- 禁：把分级解释为「安全」或「危险」。
- 禁：替医生换算分期、判断可切除性、判断复发。
- 禁：把患者看法写成结论（`viewpoint.is_conclusion` 恒为 0，有触发器守）。
- 必须：每条试验线索标注「登记状态，未核实」。
- 必须：每页有一处「不做什么」的显式说明。
