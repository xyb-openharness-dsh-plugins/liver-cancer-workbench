## 2. 缺口（按用户点名的三条 + 我额外发现的）

| 维度 | 小粉宝 | 小甘宝改前 | 判定 |
|---|---|---|---|
| **营养** | 独立一级页，3 子页；进食变化、体重趋势、专业建议留档、转成问题 | 「生活与家庭」里一张表，只有体重/小腿围/握力/食欲/限盐 | **严重不足**：HCC 的核心是肌少症 + 腹水限盐 + 食欲/味觉改变，一条表压不住 |
| **心理** | 独立一级页，4 子页；私密区默认不进一图秀/摘要/导出；照护者单独留位；身体形象·亲密·生育 | **完全没有** | **缺失** |
| **病情指标分析** | 「指标检测」子页：按类别分组卡片、CTCAE 分级徽章、背面区间、参考上限缺测给 `needsUln`、趋势断线不拼接 | 只有一图秀里的两条折线（白蛋白 + AFP） | **严重不足**：没有指标卡、没有分级对照、没有分组 |
| 二级结构 | 27 个二级 | 0 | **结构性缺陷**：一页塞 6 张卡，扫读靠滚动 |
| 收藏与回顾 | 问题清单可编辑、导出快照、导出后源变了标「已过时」 | 问题混在「复诊与试验」里，没有导出与快照 | 不足 |
| 就诊准备 / 导出 | Markdown 导出、来源与核对状态随行、私密内容默认不导出 | 无 | **缺失** |
| 资料库 / 解析 | 文档导入 + 整理草稿核对 + MinerU | 无（本阶段不做，属 M5） | 已知延后，不算本次缺口 |
| 指南出处 / 随访节奏 | refs.json + cadence.json | 无 | 延后（需先有 G3 数据模型签认） |

结论：**不是「再加几个模块」，而是补一层二级结构 + 四条独立功能线。**

## 3. 补齐方案（9 个一级 / 27 个二级）

刻意**不照抄**乳腺癌的命名与分组——HCC 的双轨主脊不能被打散。

| 一级 | 二级 | 为什么这样切 |
|---|---|---|
| 看板 | — | 不变 |
| 我的肝 | 肝病背景 / 肝功能储备 / **门脉高压** | A 轨拆开；门脉高压单独成页，因为它是**第三条独立风险线**，放在「安全线」里会被读成肿瘤并发症 |
| 我的瘤 | 肿瘤负荷 / 标志物 / 分期与可切除性 | B 轨拆开；分期与可切除性放一起，因为两者都是「医生写下的话」，不是算出来的 |
| 治疗与转化 | 治疗历程 / 转化评估 / 方案与出处 | 转化是 HCC 独有的决策节点，单独一页 |
| **指标分析**（新） | 指标卡片 / 趋势对照 / 分级说明 | 补乳腺癌的「指标检测」线，但分级用 **CTCAE v5.0**，×ULN 型必须靠化验单参考上限 |
| 安全线 | 不适与症状 / 安全事件 / 出血与脑病 | 症状从「生活」挪过来：症状在一图秀里和安全事件同一条时间轴 |
| **营养与体重**（新） | 当下困扰 / 进食与体重 / 肌少症线索 | 独立一级。三件 HCC 特有的事：肌少症（体重+小腿围+握力）、限盐（腹水）、食欲/味觉 |
| **心理与家庭**（新） | 当下感受 / 我的记录 / 支持资源 / **家里的事与早筛** | 心理 + 家属合并成一个一级，是因为 HCC 的家庭维度主要就是 **HBV 筛查与疫苗**，跟情绪支持同属「非医疗但影响治疗」的一层 |
| 复诊与回顾 | 复诊记录 / 待办与问题 / 试验线索 / **报告与导出** | 补收藏与回顾线 |

## 4. 家属线的「早筛提醒」—— 加，但只加「提示」不加「判定」

用户问：家属线是否加早筛提醒。**结论：加，做成两条并行提示，都不做分诊、不算概率。**

拆成两件不同的事，混在一起会出错：

**（1）家庭内 HBV 传播防护**（已有，`family_screening` 表）
- 每位家庭成员一行：HBsAg 状态（阳性/阴性/未检测/未知）、疫苗（完成/部分/未接种/未知）、检查日期。
- **不加**「你应该去打疫苗」这类指令；只把「未检测」「未接种」标成待办线索。
- 依据：HBV 不经日常接触传播，家庭内传播主要发生在围产期与血液暴露，提示的是**去查、去接种**，不是隔离。

**（2）HCC 高危人群随访提醒**（新增，只做「参考节点」）
- 适用对象：HBsAg 阳性家属、肝硬化家属、有 HCC 家族史者。
- 提示内容：**每 6 个月一次 AFP + 腹部超声**（《原发性肝癌诊疗指南（2024 年版）》高危人群监测建议）。原文页号与摘录入库，界面引用时不改写。
- **硬约束**：
  - 只给「距上次检查已 N 个月，参考间隔 6 个月」这种**客观间隔**，不写「你该去查了」；
  - 不出「风险高低」「得癌概率」，不做 BI-RADS/LI-RADS 式分级；
  - 「未检测」不等于「阴性」，界面上必须是两种状态，不能合并成一个灰点；
  - 提醒的**周期是参考值**，实际由医生按个人情况定，界面明写。

这两条都落在「心理与家庭 → 家里的事与早筛」这一页，与患者本人的复诊节奏（`visits.nextOn`）**分表存放**，不互相推算。

## 6. 已知没做的（诚实边界）

- 指标卡的分级只覆盖**有绝对阈值或能拿到化验单参考上限**的项；AFP、PIVKA-II 是标志物，**不做 CTCAE 分级**（标志物不是不良事件）。
- 营养页不计算摄入热量、不给膳食处方；「限盐」是抄医生原话，不是工作台建议。
- 心理页没有接入真人咨询、危机干预或转介；不做危机分级判断，出现自伤念头请直接联系当地急救或治疗团队。
- 早筛提醒不覆盖「已确诊患者的二级预防」以外的场景，也不做家系图与遗传咨询。
