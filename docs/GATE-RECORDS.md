### 为什么「同一包已加载」不等于「会话面板已验证」

`conversation` 当 React 元素渲染这个修复，确实和一图秀在同一个 tgz 里，包被加载是事实。
但上一版翻车正是栽在这里：v0.3.4 的假宿主把错路验证通过了，真机上按钮点了没反应。
**包加载 ≠ 功能可用**，而这次用户没有点过那个按钮，就不能替他说通过。
要转为「已验证」，只需一次真机点击并回一句结果，届时把这一行改掉即可，不必重开闸口。
