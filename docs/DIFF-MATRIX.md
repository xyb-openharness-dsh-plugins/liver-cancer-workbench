# DIFF-MATRIX · 与家族样板逐项差异（防换名复用）

日期：2026-10-22。基准：淋巴瘤（LymBell v0.3.0）、乳腺（PinkyPal）、卵巢、非小细胞肺癌。

| # | 对比项 | 家族样板的做法 | 小甘宝的做法（刻意不同） | 理由 |
| --- | --- | --- | --- | --- |
| 1 | 主脊 | 单线：分型 → 治疗 → 症状 → 复诊 | **双轨**：A 肝功能储备 / B 肿瘤负荷，两轨并列 | HCC 的治疗约束是肝功能 × 肿瘤，两者不能合成一个分数 |
| 2 | 风险线 | 症状页合并所有不良反应 | **门脉高压独立成第三条线**（曲张/出血/脾大/脑病） | 出血与脑病是 HCC 患者真实的急性风险，与肿瘤缩小无关 |
| 3 | 治疗路径 | 线性：一线 → 二线 → 三线 | **转化路径版本链**：不可切除 → 临界 → 可切除，每次新增一行 | 转化是「倒回去」的路径，线性时间线会丢掉「依据变了什么」 |
| 4 | 分期 | 一套分期体系 | **BCLC 与 CNLC 并存**，各一条版本链，不换算 | 中国患者两套都在听；换算等于替医生下结论 |
| 5 | 影像 | 只存结论文本 | 存 LI-RADS、**门静脉癌栓 Vp0–4**、肝外扩散、逐灶段位 | 癌栓是 HCC 独有的分期要素，决定能否切 |
| 6 | 传染病因 | 无 | **HBV 专项表 + 再激活筛查 + 家庭筛查与疫苗** | 乙肝背景是中国 HCC 的主因；这是公共卫生维度，不是「家属支持」 |
| 7 | 营养 | 体重与食欲；食管癌是「吞咽通路」 | **肌少症三件套（体重/小腿围/握力）+ 腹水限盐** | HCC 的营养问题是肌肉量与钠水潴留，不是进食通路 |
| 8 | 特异事件类型 | 常见 CTCAE | **TACE 栓塞后综合征、肝毒性、irAE、SBP、HBV 再激活** 作为独立 kind | 这些是 HCC 高频且周期性的事件，混在「其他」里查不到 |
| 9 | 指标趋势 | 单一数值线 | 上带白蛋白、下带 **AFP 对数轴**，分类节点（Child-Pugh / Vp）只画点 | AFP 跨三个数量级，线性轴会让早期值挤成一条线 |
| 10 | 评分计算 | 存医生给的评分 | Child-Pugh 存医生原值；**ALBI 由读数派生，缺项不出分** | 计算出的分数与医生记录并存会造成两个真相 |
| 11 | 观察等待 | 惰性淋巴瘤的观察等待专页 | 无等待期专页；改为 **术后监测节奏 + 复发监测**（AFP + 影像并列） | HCC 没有「先不治」的稳定路径，有的是「切完还要盯」 |
| 12 | 家庭模块 | 心理支持 / 生育与家庭 | **家庭 HBV 筛查与疫苗**（关系、HBsAg、疫苗状态） | 家庭维度在 HCC 里是可执行的医学动作，不只是情绪 |
| 13 | 临床试验 | 线索列表 | 同样只列线索，但**声明 HCC 无专属离线语料**，在线四通道逐来源终态入表 | 覆盖缺口必须可查，不能把「没查到」写成「没有」 |

## 与淋巴瘤的重合度检查

| 淋巴瘤一级页 | 小甘宝对应 | 判定 |
| --- | --- | --- |
| 看板 | 看板 | 结构同源，内容不同（单线 → 双轨） |
| 我的分型 | 我的肝 + 我的瘤 | 拆成两条线， lymphoma 的「分型」在 HCC 里没有直接对应 |
| 治疗路程 | 治疗与转化 | 保留，新增转化版本链 |
| 照护与症状 | 安全线 + 生活与家庭 | 拆成两条，因为 HCC 的急性风险与日常营养是两回事 |
| 复诊准备 | 复诊与试验 | 同名同义，内容随病种变 |

结论：一级导航 7 项里只有「复诊」语义相同，其余全部因双轨与三条风险线重构。
