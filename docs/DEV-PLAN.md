### 计分口径（避免进度条变成形容词）

- 一个里程碑 = 一张交付项清单，**完成度 = 已完成项 / 总项数**，不接受"差不多做完了"。
- **半分只用于一种情况**：做了但有明确缺口（例：前端九视图都通，但文件路径与六步要求不一致）。
- **闸口不因进度高而通过**：M5 到 70% 也不能替 G3 说话，反过来 G3 签认也不会自动把 M5 变成完成。
- 未开始就写 0，不写"初期"。
