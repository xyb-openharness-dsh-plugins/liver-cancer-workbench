# 小甘宝 HepPal · SPEC（v0.1，2026-10-22）

> 状态：M1 调研稿，等 G1 签认。签认前不改业务实现。

## 1. 一句话

给肝细胞癌患者与照护者的本机工作台：**把「肝还剩多少储备」与「瘤负荷到哪一步」两条线同时理清，并把医生给过的分期、可切除性结论按时间排好**，让每一次门诊都能接着上一次说。

## 2. 服务对象与阶段

| 人群 | 主要困惑 | 本工作台给什么 |
| --- | --- | --- |
| 刚确诊、还没定方案 | 两套分期（BCLC / CNLC）听不懂；为什么别人能切我不能 | 分期原文 + 可切除性结论 + 依据；两条线的基线 |
| 正在做 TACE / HAIC | 发烧、疼、乏力是不是正常；下次什么时候做 | 栓塞后事件记录、肝功能复查节奏、待办 |
| 正在靶免治疗 | 肝酶升高是药的问题还是肝病本身；要不要停 | 肝酶/胆红素趋势与事件记录（不判断停药） |
| 被判「不可切除」后在转化 | 有没有机会切；依据变了没有 | 可切除性版本链 + 每次 MDT 依据 |
| 切除/消融术后 | AFP 升一点是不是复发；多久查一次 | 术后监测时间线 + 影像与 AFP 并列 |
| 照护者 | 家里其他人要不要查乙肝；出血了怎么办 | 家庭筛查记录 + 医生交代过的就诊提示 |

覆盖：早期（切除/消融）、中期（局部治疗）、晚期（系统治疗）、术后随访。**不覆盖**：儿童肝母细胞瘤、肝内胆管癌（另立病种）、移植后长期免疫管理（只记录移植评估结论）。

## 3. 不做什么（硬边界）

- 不诊断、不分期、不判断可切除性、不判断复发。
- 不给治疗建议、不给停药/减量/补服建议、不给预后与生存期。
- 不做试验匹配与排序；只列线索，标注「登记状态，未核实」。
- 不计算 Child-Pugh 评分（医生记录原值）；ALBI 只作派生展示，缺项不出分。
- 不把「患者自己的理解」写成结论。

## 4. 主脊：双轨

```
A 轨 · 肝功能储备             B 轨 · 肿瘤负荷
白蛋白 / 胆红素 / INR          结节数 / 最大径 / LI-RADS
血小板 / Child-Pugh / ALBI     门静脉癌栓 Vp / 肝外扩散 / AFP / PIVKA-II
腹水 / 肝性脑病
        ↘ 两轨并列展示，永不加总、永不互相折算 ↙
             第三条独立风险线：门脉高压（曲张/出血/脾大）
```

为什么不是单一评分：HCC 的治疗选择由「肝功能能不能承受」与「肿瘤能不能控」共同决定；合成一个分数会掩盖真实约束，也会让患者误以为「分数没变就是没变化」。

## 5. 页面树（9 个一级 / 27 个二级）

> 2026-10-23 改：原 7 个一级页、0 个二级，一页铺 6 张卡。按用户「功能线少了太多了，对比下乳腺癌」
> 的意见补成 9 个一级 / 27 个二级。切法与取舍见 [FEATURE-GAP-BREAST.md](FEATURE-GAP-BREAST.md)。

| 一级 | 二级 | 回答什么 | 核心实体 |
| --- | --- | --- | --- |
| 看板 | — | 今天我最该知道哪两件事 | 双轨一图秀、6 张指标卡、最近安全事件、待办 |
| 我的肝 | 肝病背景 / 肝功能储备 / 门脉高压 | 我的肝是什么底子，还剩多少 | 病因、肝硬化、Child-Pugh、ALBI、HBV、曲张与出血 |
| 我的瘤 | 肿瘤负荷 / 标志物 / 分期与可切除性 | 瘤在哪、多大、有没有癌栓 | 病灶、LI-RADS、Vp、AFP/PIVKA-II、BCLC/CNLC、可切除性版本链 |
| 治疗与转化 | 治疗历程 / 转化评估 / 方案与出处 | 我走过哪几条路，为什么换 | 治疗事件、转化路径、机构与来源 |
| 指标分析 | 指标卡片 / 趋势对照 / 分级说明 | 我的数到底在什么位置 | `metric_def`/`metric_reading`、CTCAE v5.0 对照 |
| 安全线 | 不适与症状 / 安全事件 / 出血与脑病 | 哪些事会突然变危险 | 栓塞后综合征、肝毒性、irAE、出血、脑病、腹水、SBP、再激活 |
| 营养与体重 | 当下困扰 / 进食与体重 / 肌少症线索 | 吃、体重、肌肉 | 体重/小腿围/握力、食欲、限盐、限水 |
| 心理与家庭 | 当下感受 / 我的记录 / 支持资源 / 家里的事与早筛 | 我心里的事，和家里其他人 | 私密记录、照护者记录、家庭 HBsAg/疫苗、高危随访间隔 |
| 复诊与回顾 | 复诊记录 / 待办与问题 / 试验线索 / 报告与导出 | 下次带什么去，还有什么机会 | 复诊、待办、问题、试验线索、导出快照 |

**三条硬约束（页面切分不能破）：**

1. 「我的肝」与「我的瘤」并列，永不加总成一个分数；
2. 门脉高压独立成页，不塞进「安全线」当治疗副作用；
3. 「指标分析」只做对照，不给处置；AFP/PIVKA-II 是标志物，不做 CTCAE 分级。

## 6. 事实四层

| 层 | 表 | 规则 |
| --- | --- | --- |
| 文档 | `document` | 原件只读；失败不产候选 |
| 候选 | `candidate` | 永远是候选；逐项确认才进事实层；接受 ≠ 审核 |
| 记录 | `liver_reserve` / `tumor_assessment` / `safety_event` / `treatment_event` … | 显式 NULL；不改历史 |
| 指标 | `metric_def` / `metric_reading` | 只有数值型进趋势；分类只画节点 |

医生结论（分期、可切除性）单独建版本链表，`is_current` 唯一；更正只新增行。

## 7. 与家族样板的刻意差异

见 [DIFF-MATRIX.md](DIFF-MATRIX.md)。最关键三条：

1. 双轨主脊（淋巴瘤/乳腺是单线「分型→治疗→随访」）。
2. 门脉高压是第三条风险线，不与肿瘤负荷合并。
3. 转化治疗是「倒回去」的路径，需要版本链而不是线性时间线。

## 8. 成功标准（G2 可验）

- 打开 `prototypes/v0.1/index.html`（`file://`）无构建、无 4xx、控制台 0 error。
- 9 个一级页、27 个二级页全部可切；`aria-current` 与内容一一对应；两个档案切换后指标同构。
- 双轨图：上带白蛋白、下带 AFP 对数；分类节点只画点；单点不连线；末点标签不越界。
- 看板的 6 张指标卡可翻转，背面是迷你折线；分类指标不伪造折线。
- 「指标分析」15 张卡按 5 组排列，CTCAE 只在 ≥1 级时挂徽章；缺参考上限的 ×ULN 项显示「需参考上限」而不给级。
- 「心理与家庭」的私密记录不出现在一图秀、就诊摘要与导出中。
- Agent 面板可开、可收起、可拖宽（25%–45%）；窄屏 820 px 无横向溢出。
- 每页至少有一句「不做什么」的显式说明。
