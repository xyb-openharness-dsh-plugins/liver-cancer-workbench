# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：肝细胞癌患者与照护者；覆盖早期切除/消融、中期局部治疗、晚期系统治疗与术后随访全周期

场景：患者把影像、化验、病理与治疗记录整理成两条线：肝功能储备（Child-Pugh/ALBI）与肿瘤负荷（结节/癌栓/AFP），并记录门脉高压、肝性脑病、TACE 栓塞综合征、靶免肝毒性与 HBV 再激活风险

核心流程：
1. 选择本机资料目录，导入或手工登记化验、影像、出院小结
2. 核对候选值，确认后进入事实层（接受不等于审核）
3. 在双轨看板看肝功能与肿瘤负荷的变化，标注医生给出的分期与可切除性结论
4. 整理复诊问题与临床试验线索，交给原生 Agent 会话并归档结果

完成结果：两条轨道的记录与来源可追溯、可回顾，医生结论与患者看法分开存放，资料保存在用户明确选择的目录

初始布局选择：business-first
