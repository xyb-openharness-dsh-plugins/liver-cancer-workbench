# 工作台设置：设计与实现 v0.2

- 首次：2026-10-22（草案，starter 模板占位）
- **本次更新：2026-10-24（v0.3.6，改为"实际实现说明"）**：草案里的每一项都标了「已做 / 不做 / 未做」，
  空白处不再留 `...`——留 `...` 等于骗下一个接手的人"这里只是没写完"。
- 代码：`lib/client.js` 的 `ViewSettings` + `dsh/settings.js`（Token 唯一实现）+ `dsh/api.js` 三条路由。

## 入口与边界

- 一级导航第 12 项「设置」（`VIEWS` 末位，排在「导入与候选」之后）。**不做弹层**：
  设置要能被截图、被慢慢读，弹层一按 ESC 就没了。
- 不覆盖宿主的公共设置、导航、模式、权限与原生 Agent——本工作台只管三件事：
  **资料目录（只读）/ 扫描件解析 Token / 字号**。
- 无配置、读取失败、坏文件时**都能进入设置页**：状态块显示原因，不弹"配置错误，无法打开"。
- 低频解释（云端代价、格式白名单、为什么不能换目录）放在块尾的 `wb-hint` 小字里，不占主流程。

## 资料目录

- **只显示，不修改**。判定源是 `/health` 的 `dir`（服务端真实业务目录），不是前端猜的 cwd。
- 状态只有两档：`就绪` / `未就绪`。**"路径存在"不等于"初始化成功"**，所以不按 `existsSync` 说就绪。
- 为什么不做切换：customFrame 下目录与会话绑定，换目录要连宿主会话一起换，业务侧改了只会得到
  "会话还挂在旧目录"的半死状态。界面明写"换目录请从 Desktop 的工作台设置里做"。

## 扫描件解析与凭据（MinerU）

| 项 | 实现 |
| --- | --- |
| 输入 | `type="password"` + `autoComplete="new-password"`，**保存成功后立刻清空输入框**（明文不留在屏幕上） |
| 显示 | 只显示掩码 `maskToken()`（首 4 + `****` + 尾 2）与来源文字（"已保存于 …" / "临时使用环境变量" / "尚未配置"） |
| 位置 | 优先级 **显式参数 > 密钥文件 > 环境变量**；文件默认 `~/.heppal/secrets/mineru.json`，仓库内 `.secrets/mineru.json` 存在时优先，`HEPPAL_MINERU_SECRET` 可覆盖路径 |
| 写盘 | 同目录 tmp → `chmod 600` → `rename`；目录 700；**只改 `token` 一个键，其它键原样保留**；写失败不清空旧文件 |
| 清除 | 只删 `token` 键，文件空了就删文件；幂等。文件清空后若环境变量还有一把，界面必须显示"清除后它会接管" |
| 坏文件 | 抛 `settings_broken_file` 并显示原因，**不当成"没配"**——当成没配会让下一次保存静默覆盖一份可能还能救的文件 |
| 校验 | 空 / <8 / >1024 / 含空白 / 不在 `[A-Za-z0-9._-]` 一律 400，错误码 `invalid_token` + `field:'token'` |
| 明文 | 原文**永不回界面、不进日志、不进错误消息、不进导出**。错误消息里只带申请地址 `https://mineru.net/apiManage/token` |

**云端代价要写在页面上，而不是写在文档里**：原件会上传到 mineru.net，且必须由用户点「解析」才发，
工作台不自动上传；TXT / MD / CSV 不走云端，在本机直接读；HTML 不在白名单（接口明确拒收 `-10002`）。

授权按**每次点击**取得（按钮就在队列行上），设置里"记住 Token"不等于"以后自动上传"。

## 字号

- 三档：标准 / 大字 / 特大 = `--tz` 1 / 1.15 / 1.32（家族口径）。设置页 `role="radiogroup"` 直接选，
  顶栏 chip 点一下循环三档，两边写同一个 localStorage 键 `ganbao.liver.font-scale.v1`。
- 唯一开关原则：CSS 里每处字号都是 `calc(NNpx * var(--tz))`。任何一处写死 px，就等于那一处不跟着放大。

## 保存与可访问性

- 保存：按钮 `disabled` 仅在"正在写"或"输入为空"时；错误用 `role="alert"` 红字写在表单下，
  成功用 `role="status"`。**不清空用户已输入的内容**（失败时输入框保留，方便改一个字符再试）。
- 焦点：输入框 `:focus-visible` 有 2px 描边；档位是 `role="radio"` + `aria-checked`，Tab 可到、回车可选。
- 窄窗：`.wb-set-tiers` 三列在窄屏仍三列（每列是"标准 / 1.00 倍"两行短字，不会挤）；
  表单 `flex-wrap`，按钮换行不裁切。
- 大字：三档字号本身即验收手段——切到"特大"后设置页不溢出、不裁切。
