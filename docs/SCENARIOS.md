# 场景（S1–S12）

日期：2026-10-22。每条写清：谁、在什么时候、想回答什么、工作台给什么、**不给什么**、落在哪一页。

## S1 · 刚拿到「肝细胞癌」四个字

- **谁**：58 岁男性，乙肝 20 年，体检超声发现 6 cm 结节，增强 MRI 写 LR-5。
- **想回答**：这是癌吗？到哪一期？为什么医生说要先做介入而不是开刀？
- **给**：诊断原文与影像描述、LI-RADS 原值、BCLC 与 CNLC 两条并列、医生写的「不可切除」结论与依据（残肝 31%、Vp2）。
- **不给**：分期换算、严重程度排序、「你应该手术」。
- **落点**：我的瘤 / 负荷与侵犯、治疗与转化。

## S2 · 确诊后第一次门诊前的 48 小时

- **谁**：女儿替父亲整理资料，手里有三份报告和一堆照片。
- **想回答**：我该带什么？该问哪几个问题？哪些数字要记住？
- **给**：资料清单、两条线的基线值、10 个问题的模板（可编辑）、把问题带去门诊。
- **不给**：替家属决定问什么、替医生回答。
- **落点**：复诊与试验 / 待办与问题。

## S3 · 第一次 TACE 后的第三个晚上

- **谁**：患者在家，38.5℃，右上腹疼，恶心。
- **想回答**：这算正常反应还是要回医院？
- **给**：既往栓塞后事件记录、医生当时交代的处理原话、就诊提示（发热门槛按病历原文）、联系团队入口。
- **不给**：是否急诊的分诊结论、退烧药建议。
- **落点**：安全线 / 安全事件记录。

## S4 · 靶免治疗第 4 周期，肝酶升高

- **谁**：ALT 96、AST 88、总胆红素 34，基层医院建议停药，患者拿不准。
- **想回答**：这是药肝还是我原来的肝病？以前也这样吗？
- **给**：ALT/AST/胆红素时间线、与用药起止对齐、上次同类事件与处理、医生记录的原话。
- **不给**：「应该停药 / 减量 / 换药」。
- **落点**：安全线 / 肝酶与胆红素；治疗与转化 / 时间线。

## S5 · 「不可切除」变成「临界可切除」

- **谁**：完成 2 次 TACE + 4 周期仑伐替尼联合免疫后，MDT 改口。
- **想回答**：依据变了什么？是癌栓退了还是瘤小了？下次评估看什么？
- **给**：三次可切除性结论并列（日期、医生、依据原文、残肝比例）、同期影像与 AFP 变化。
- **不给**：「转化成功了吗」「该不该手术」。
- **落点**：治疗与转化 / 转化路径；我的瘤 / 可切除性评估。

## S6 · 术前：要切多少肝

- **谁**：被告知可以手术，但担心「切完肝不够用」。
- **想回答**：残肝 46% 是什么概念？术前要不要停靶免？
- **给**：残肝比例原文、Child-Pugh 与 ALBI 趋势、患者问题清单（含「停药多久」）。
- **不给**：残肝够不够的判断、停药方案。
- **落点**：治疗与转化；复诊与试验 / 问题。

## S7 · 术后第 5 个月，AFP 从 5.1 到 8.4

- **谁**：46 岁女性，S6 段切除，病理 MVI 阴性。
- **想回答**：升了 3 点是不是复发？要不要提前做影像？
- **给**：术前/术后 AFP 全部时点、影像结论并列、医生定的复查节奏、下一次预约。
- **不给**：「可能是复发」「复发概率」。
- **落点**：我的瘤 / 时间线；复诊与试验。

## S8 · 家庭里第二个 HBsAg 阳性

- **谁**：患者母亲查出 HBsAg 阳性，女儿 16 岁已接种。
- **想回答**：会不会是家里传的？其他人还要查什么？
- **给**：家庭筛查记录（关系、HBsAg、疫苗状态、检查日期）、患者自己的抗病毒药与筛查日期。
- **不给**：传播链推断、接种方案、停药建议。
- **落点**：生活与家庭 / 家里的事；我的肝 / HBV 记录。

## S9 · 半夜黑便

- **谁**：照护者发现黑便一次，患者头晕。
- **想回答**：现在去急诊还是等门诊？
- **给**：静脉曲张分级与出血史、套扎记录、降门压药、医生交代过的就诊提示。
- **不给**：分诊判断、止血建议。
- **落点**：安全线 / 门脉高压与脑病。

## S10 · 腹水与「吃不下」

- **谁**：62 岁男性，腹胀、食量下降，三个月瘦 3.2 kg。
- **想回答**：是腹水还是没营养？限盐到底限多少？
- **给**：体重/小腿围/握力趋势、腹水分级、医生交代的限盐原话、症状自评。
- **不给**：利尿剂调整、蛋白粉推荐、限盐具体克数的医学建议（只显示医生原话）。
- **落点**：生活与家庭 / 营养与肌少症。

## S11 · 二线失败后找试验

- **谁**：系统治疗两线后进展，想找还有没有机会。
- **想回答**：国内有哪些在招的 HCC 研究？我要准备什么？
- **给**：2026 试验线索列表（来源、登记号、期别、状态「未核实」）、入组问题清单、把线索带去门诊。
- **不给**：排序、匹配、「你适合哪个」、疗效预测、药物推荐。
- **落点**：复诊与试验 / 临床试验线索。

## S12 · 换院与二次意见

- **谁**：准备去外地医院，带切片与影像。
- **想回答**：原医院的结论会不会被推翻？要带哪些东西？
- **给**：历次结论与依据、原始报告归档、资料清单、问题清单。
- **不给**：判断哪家医院更好、替医生比较方案。
- **落点**：治疗与转化；复诊与试验。

## S13 · 乏力、头晕，化验单又说血象低

- **谁**：靶免治疗中，人软，家属说"脸色不好"。
- **想回答**：我这算几级？要不要停？
- **给**：自评感受（0–10）与血常规（WBC / ANC / Hgb）**并排**，附 CTCAE v5.0 客观区间对照；缺参考上限时明写"需参考上限"。
- **不给**：把两边写成因果（"因为中性粒低所以头晕"）、停药 / 减量建议、升白针推荐。
- **落点**：安全线 / 不适与症状；指标分析 / 指标卡片。

## S14 · 体重还行，但人瘦了一圈

- **谁**：肝硬化背景，体重 3 个月掉了 3 kg，衣服松了。
- **想回答**：是不是营养不良？要不要吃营养粉？
- **给**：体重 + 小腿围 + 握力三件并列与逐次变化、食欲、医生交代的限盐限水原话。
- **不给**：SARC-F 评分、肌少症诊断、蛋白粉 / 口服营养补充的品牌与剂量、热量计算。
- **落点**：营养与体重 / 肌少症线索。

## S15 · 不敢跟家里人说害怕

- **谁**：术前等待期，睡不着，怕开刀后肝不够用。
- **想回答**：这种状态正常吗？我该找谁？
- **给**：私密记录区（默认不进一图秀 / 摘要 / 导出）、照护者自己的独立记录位、如何开口求助的两句话示例。
- **不给**：心理量表评分、"中度焦虑"这类判定、危机分级；出现自伤念头时明写"直接联系当地急救或治疗团队"。
- **落点**：心理与家庭 / 当下感受、我的记录。

## S16 · 儿子还没查过乙肝

- **谁**：患者 HBsAg 阳性，29 岁儿子从没查过，也没接种。
- **想回答**：他要不要查？多久查一次？
- **给**：家庭成员逐人状态（HBsAg 阳性 / 阴性 / **未检测** / 未知，四种分开）、疫苗状态、
  「距上次检查 N 个月，参考间隔 6 个月」的客观间隔；引用《原发性肝癌诊疗指南（2024 年版）》高危人群监测建议。
- **不给**："你该去查了"的命令句、得癌概率、家系图与遗传咨询、把家属结果写进患者病程。
- **落点**：心理与家庭 / 家里的事与早筛。

## 刻意没有的场景

- 「帮我算还能活多久」——不做预后。
- 「这个方案和那个方案哪个好」——不做方案比较。
- 「帮我看这张片子」——不做影像判读。
