# 患者流程：三个关键时刻

日期：2026-10-22。页面树由这三条流程反推，**不从医生流程照搬**。每条写清：患者在什么时刻最难受 → 打开哪一页 → 得到什么产物 → 工作台明确不给什么。

---

## 流程 A · 确诊后那两周（最难受的时刻：拿到报告，等第一次门诊）

| 时刻 | 患者状态 | 打开 | 得到 |
| --- | --- | --- | --- |
| 拿到增强 MRI 当天 | 只认得「癌」字，不认得 LR-5、Vp2 | 我的瘤 / 负荷与侵犯 | 影像描述原文、LI-RADS 与 Vp 原值、结节数与最大径 |
| 第二天 | 想知道「严重吗」，但没人回答 | 看板 | 两条线基线：肝储备一列、肿瘤一列；第一张卡片就是 Child-Pugh |
| 门诊前一天 | 怕忘、怕问错 | 复诊与试验 / 待办与问题 | 问题清单（可编辑）、要带的资料清单 |
| 门诊当天 | 听到两套分期，记不住 | 我的瘤 / 分期 | 医生结论原始记录：BCLC 与 CNLC 各一条，注明谁说的、依据是什么 |
| 听到「不能切」 | 最崩溃的一刻 | 治疗与转化 | 「不可切除」结论 + 依据 + 是否被判过「转化意图」治疗 |

**产物**：一份可打印/可带走的「确诊档案」——两条基线 + 分期 + 可切除性结论 + 问题清单。
**不给**：分期换算、严重程度、手术建议。

---

## 流程 B · 一次 TACE 住院与回家（最难受的时刻：出院后第一晚发烧）

| 时刻 | 患者状态 | 打开 | 得到 |
| --- | --- | --- | --- |
| 入院当天 | 不知道这次做的是第几次、上次做完多久了 | 治疗与转化 | 治疗时间线：每次 TACE 的起止与疗效记录 |
| 术后当晚 | 发热 38.5℃、腹痛 | 安全线 | 既往栓塞后事件记录 + 医生交代的处理原话 + 就诊提示 |
| 回家第三天 | 乏力加重，胃口差 | 生活与家庭 | 症状自评、营养记录（体重/小腿围） |
| 出院后两周复查 | 想知道下次什么时候做、肝功能有没有掉 | 我的肝 / 储备时间线 + 复诊与试验 | 白蛋白/胆红素/血小板趋势 + 下次预约 |

**产物**：一次住院的完整闭环——事件记录 + 肝功能变化 + 下次节奏。
**不给**：是否急诊、退热与止痛建议、「这次要不要再做」。

---

## 流程 C · 一次常规复查（最难受的时刻：抽血后等 AFP）

| 时刻 | 患者状态 | 打开 | 得到 |
| --- | --- | --- | --- |
| 复查前一周 | 焦虑，「怕 AFP 涨」 | 看板 → 指标卡 | 全部历史时点（不是最近一次），单点只有一次就明写「只有 1 次记录」 |
| 复查当天 | 拿到化验单，看不懂 | 我的肝 / 化验时间线 | 逐项原值 + 参考范围原样 + Child-Pugh 与 ALBI（缺项不出分） |
| 医生说完 | 说完就忘 | 复诊与试验 / 复诊记录 | 医生摘要原话 + 下次复查日期 |
| 回家后 | 想记录自己的担心 | 生活与家庭 / 我想说的 | 看法记录，标注「不是医生结论」，不进趋势 |

**产物**：一次复查的前后对照 + 医生结论 + 待办。
**不给**：「是不是复发」「要不要提前复查」的判断。

---

## 页面树反推说明

- 流程 A → 需要「我的瘤」+「治疗与转化」两个一级页，而不是笼统的「我的病情」。
- 流程 B → 需要「安全线」独立成一级页（TACE 的副作用是节律性的，混在「症状」里会丢）。
- 流程 C → 需要「我的肝」与「我的瘤」分开（复查时两条线是分开看的）。
- 三条流程都指向「问题清单」→ 所以「复诊与试验」必须是一级页，不藏在设置里。
